Preferences › Appearance: three layouts

The same settings in three arrangements. Style, theme, mode, contrast, density, text size and font are separate settings that mix freely. Every direction shows the same moment: the app is using Classic with the Light theme, and the user is previewing Loft with the Taiga theme before applying it. Everything is clickable. Esc or Revert discards, Apply commits.

Preview-first

A. Preview-first

  • Biggest, most convincing preview. Best for the “falls for Loft in one click” moment.
  • Pending and Applied switch makes the change easy to judge.
  • Lower settings (density, text size, font) are changed with the preview off screen.

B. Split pane

  • Every control has live feedback, which matters most for density and text size.
  • Scales to new themes and styles without changing the layout.
  • Smaller preview, and cramped cards in a 360px column.

C. Looks gallery

  • Fastest path for most people, and the same looks as onboarding.
  • Curated pairs avoid clashing combinations.
  • Hides free mix. A custom mix needs its own card and has no large preview.

Theme author guide (link target)

“Get more themes or make your own” opens the theme author docs. A theme is a W3C DTCG JSON token file, for example themes/taiga.tokens.json, with colour, type, radius and shadow tokens for light, dark and Increase contrast. Styles read only these shared tokens, so a new theme works with Classic, Loft, Taiga, Darkside and Less-is-more without extra work.
